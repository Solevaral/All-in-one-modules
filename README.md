# All-in-one — каталог модулей

Удалённый каталог для [All-in-one](https://github.com/Solevaral/All-in-one). Каркас загружает `catalog.json` при запуске и раз в несколько часов, кэширует его и объединяет со встроенным каталогом: запись с тем же `id` перекрывает встроенную.

В каталоге **нет версий** — только где искать модуль. Последнюю версию каркас спрашивает у GitHub Releases репозитория модуля, поэтому менять этот файл нужно только при появлении нового модуля или смене его адреса.

## Как добавить модуль

1. Допишите запись в `modules` в `catalog.json`. Формат и все поля описаны в [docs/MODULES.md](https://github.com/Solevaral/All-in-one/blob/main/docs/MODULES.md).
2. Если модулю нужна новая версия каркаса, укажите её в `minHostVersion`: старые каркасы покажут запись, но не дадут её установить.
3. Программа должна поддерживать режим `--hosted` и протокол HostLink. Готовая реализация для .NET — один файл [HostLink.cs](https://github.com/Solevaral/All-in-one/blob/main/docs/reference/HostLink.cs).
